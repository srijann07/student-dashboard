# Student Performance Dashboard

An interactive student-performance dashboard built with Python, Streamlit, Pandas, and Plotly.

## Highlights

- Interactive dashboard UI with Streamlit
- Data loading and transformation with Pandas
- Interactive charts with Plotly
- Student-performance data exploration
- Minimal setup for local experimentation

## Tech Stack

Python · Streamlit · Pandas · Plotly

## Project Structure

```text
student-dashboard/
└── 2443169/
    ├── student-dashboard.py
    ├── student_performance.csv
    └── requirements.txt
```

## Run locally

```bash
cd 2443169
pip install -r requirements.txt
streamlit run student-dashboard.py
```
